PRO Client Finder

Инструмент для поиска потенциальных клиентов среди компаний.

Что делает
- Ищет компании через DaData API по городу и сфере деятельности
- Анализирует сайт: есть ли SSL, не конструктор ли, нет ли странного домена
- Анализирует email: общий ящик, бесплатный домен, странный домен
- Помечает приоритетных клиентов (тем, кому нужен сайт)
- Экспортирует результаты в CSV

Технологии
- HTML, CSS, JavaScript (чистый, без фреймворков)
- DaData API (suggestions/party)

Как запустить
1. Скачайте файл index.html
2. Получите API-ключ DaData на [dadata.ru](https://dadata.ru/api/)
3. Откройте файл в браузере
4. Введите ключ в поле на странице — он сохранится в localStorage

Статус
Прототип. Компании берутся из DaData (реальные), контакты пока эмулируются.
В планах: подключение реальных источников (2GIS, Яндекс.Карты, парсинг сайтов).
